# נגישות: הצהרת נגישות ותפריט התאמות

תאריך: 2026-08-01

## המטרה

להעמיד את תמחורולוג בדרישות תקנות שוויון זכויות לאנשים עם מוגבלות (התאמות
נגישות לשירות), התשע"ג-2013, לפי ת"י 5568 רמה AA. שני מרכיבים גלויים: דף
הצהרת נגישות ותפריט התאמות אישיות.

אילוץ מנחה אחד, והוא גובר על כל השאר: **התוספת לא משנה את התנהגות האפליקציה
הקיימת בשום צורה.** לא את הפריסה, לא את הצבעים בברירת מחדל, לא את זרימת
הנתונים, לא את הביצועים במידה מורגשת.

## למה לא תוסף חיצוני

נשקל ונדחה. תוסף overlay מצד שלישי רץ על דף שבו לקוח מקליד את שמו המלא
ומאשר הצעת מחיר מחייבת; הוא עולה כסף חודשי; הוא פוגע בזמן הטעינה; הוא ידוע
בהתנגשויות עם פריסות RTL; והוא איננו תחליף מוכר לתיקון האתר עצמו. מיושם כאן
בקוד, בתוך מערכת הטוקנים שכבר קיימת.

## עקרון היישום

כל ההתאמות מיושמות כדריסה של משתני CSS קיימים, מתחת לסלקטורים התלויים בתכונת
data על תגית `<html>`:

```css
html[data-a11y-contrast="high"] { --background: #ffffff; ... }
```

בברירת מחדל התכונות לא קיימות, ולכן אף כלל חדש לא מתאים לשום אלמנט. זהו גם
מקור הביטחון שהאתר הקיים לא משתנה, וגם הסיבה שהמנגנון יחזיק בדפים שייכתבו
בעתיד: כל דף שצובע דרך הטוקנים מקבל את ההתאמות בחינם.

אין הזרקת CSS דינמי מ-JavaScript ואין מניפולציה של ה-DOM מעבר לכתיבת התכונות
על `<html>`.

## מבנה

| קובץ | תפקיד |
|---|---|
| `src/lib/a11y.ts` | תצורה: פרטי רכז הנגישות ותאריך עדכון ההצהרה. טיפוס ההגדרות, ברירות המחדל, מפתח האחסון, ורשימת ההתאמות. |
| `src/components/a11y/settings-script.tsx` | סקריפט inline חוסם. קורא localStorage וחותם תכונות על `<html>` לפני הצביעה הראשונה. |

| `src/app/accessibility/page.tsx` | דף ההצהרה. Server component סטטי. |

קבצים שמשתנים: `src/app/globals.css` (שכבת הדריסות), `src/app/layout.tsx`
(הרכבה + skip link), `src/app/sitemap.ts` (הוספת דף ההצהרה).

### התמדה

ההעדפות נשמרות ב-localStorage תחת מפתח בגרסה (`tamchurolog:a11y:v1`), בלבד.
לא בדאטהבייס, לא בעוגייה, ולא נשלחות לשרת. אין נגיעה ב-Supabase, ב-RLS,
ב-middleware או בשום Server Action. קריאה כושלת או JSON פגום נופלים חזרה
לברירות המחדל בשקט — העדפת תצוגה לעולם לא שוברת עמוד.

הסקריפט החוסם קיים כדי למנוע הבזק: בלעדיו, מי שבחר ניגודיות גבוהה יראה רבע
שנייה של המראה הרגיל בכל ניווט.

## הכפתור והתפריט

כפתור צף בפינה התחתונה־שמאלית — הצד ההפוך לכיוון הקריאה, כדי שלא יכסה טקסט.
אייקון הנגישות המקובל, `aria-label="פתיחת תפריט נגישות"`, 48px כמו שאר יעדי
המגע באתר, נושא `print-hide`.

התפריט הוא `<dialog>` נייטיב הנפתח ב-`showModal()`. הבחירה אינה סגנונית: היא
מספקת מהדפדפן סגירה ב-Escape, לכידת מיקוד, ונטרול הרקע. בסגירה המיקוד חוזר
לכפתור הפותח.

ההתאמות:

1. **גודל טקסט** — רגיל / גדול / גדול מאוד. 100% / 112.5% / 125% על
   `font-size` של `<html>`. כיוון שכל האתר מודד ב-rem, טקסט, ריווח ויעדי מגע
   גדלים יחד והפריסה נשארת פרופורציונלית.
2. **ניגודיות** — רגיל / ניגודיות גבוהה / כהה. דריסת משתני צבע בלבד.
3. **הדגשת קישורים** — קו תחתון ומסגרת לכל `<a>`.
4. **עצירת אנימציות** — ביטול `transition` ו-`animation`.
5. **פונט קריא** — החלפת `--font-sans` למחסנית בעלת ניקיון צורה גבוה בעברית.
6. **סמן עכבר גדול** — סמן SVG מוגדל.
7. **איפוס הגדרות** וקישור להצהרת הנגישות.

הכל נשלט מקלדת, עם `focus-visible` גלוי, בהתאם לדפוס הקיים ב-`button.tsx`.

## ביקורת נגישות על האתר הקיים

הצהרה שאומרת "ניווט מקלדת מלא" בזמן שאין skip link היא הצהרה כוזבת. לפני
כתיבת ההצהרה נעשית ביקורת על הקוד הקיים:

- skip link לתוכן הראשי
- נוכחות `<main>` יחיד בכל עמוד
- `focus-visible` על כל אלמנט אינטראקטיבי
- תווית מקושרת לכל שדה טופס
- `alt` לכל תמונה, ו-`aria-hidden` לאייקונים דקורטיביים
- יחסי ניגודיות, ובפרט `--muted` (#667085) על שני משטחי הרקע
- מצב שאינו מסומן בצבע בלבד (תגי הסטטוס)
- שגיאות טפסים המוכרזות לקורא מסך

כל פער שיימצא — או שיתוקן, או שייכנס לסעיף ההחרגות בשמו המפורש. ממצאי הביקורת
מדווחים למשתמש לפני התיקון.
